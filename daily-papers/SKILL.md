# 金融期刊周报

面向用户的一句话入口。正常情况下用户每周说一次：

- `本周期刊新论文` / `本周 JF 推荐`
- `过去两周期刊推荐`
- `过去一个月期刊新论文`

## 执行原则

1. **解析窗口**：
   - `本周` / `这周` / `周报` / 未指定 → `--days 7`
   - `过去两周` → `--days 14`
   - `过去一个月` / `本月` → `--days 30`
   - `过去 N 天` → `--days N`（最小 7，因为期刊不每天发文）

2. 自动调用 `/daily-papers-fetch`（传入对应 `--days`）

3. **关键短路逻辑**：第 1 步如果发现期刊在窗口内**没有新论文**，`/tmp/daily_papers_enriched.json` 会是空数组 `[]`。这种情况下**直接告诉用户"本{窗口}没有期刊新论文，下{下一个周期}再来"，不要继续跑后续步骤**。

4. 第 1 步有结果 → 调用 `/daily-papers-review` 生成审稿点评 + 分流表

5. **流水线在这里结束。绝对不要调用 `/daily-papers-notes`，绝对不要触发 paper-reader 或自动生成任何论文笔记。**

6. 收尾时用一段话告诉用户：
   - 涉及哪些期刊、各几篇（必读 / 值得看 / 可跳过分布）
   - 推荐文件路径（`{DAILY_PAPERS_PATH}/YYYY-MM-DD-期刊审稿.md`）
   - **明确的下一步指引**（必须照下面格式给）：

     ```
     📥 想深读哪几篇？操作步骤：

     1. 在 Obsidian 里打开本期审稿，看分流表里的 🔥 必读 / 👀 值得看
     2. 用 Zotero 浏览器插件（学校 SSO + EZproxy/VPN）把对应论文 PDF 抓进 Zotero
        - 点 DOI 链接 → 学校代理 → 出版社页面 → 点 Zotero Connector 图标
     3. 抓完后回来，说「读一下 Zotero 里的 {论文标题}」
        - 这会触发 paper-reader，用金融模板生成完整深度笔记（含 Gap & Future Directions）
     4. 多篇精读建议每次只触发一篇，paper-reader 一篇耗时较长

     注意：本期审稿文件已经包含了所有候选论文的初步点评，先看审稿决定优先级，再决定抓哪几篇。
     ```

## 重要约束

- 不要先要求用户手动跑内部命令。这一句就是完整入口
- 抓不到新论文是常态（期刊一周可能 0-3 篇），直接退出比生成空文件好
- **绝对不要自动生成论文笔记**——只有用户手动用 Zotero 抓 PDF 后说"读一下 Zotero 里的 XXX"才走 paper-reader
- 即使用户在审稿点评里看到很想读的论文，也不要主动调用 paper-reader——必须等用户明确触发
- `/daily-papers-notes` 这条 skill 已基本不用（保留以防特殊场景），周报流水线不调用它

## 自动化建议

如果用户想做定时任务（如周一自动跑一次），用 `/loop 7d 本周期刊新论文` 或在 cron 里跑 `本周期刊新论文`。
